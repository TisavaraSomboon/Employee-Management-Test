# Employee-Management-Test

# Er diagram

# endpoint

- Create
```bash
POST /api/employees
```
- Read
```bash
GET /api/employees or /api/employees/[id]
```
- Update
```bash
PUT/PATCH /api/employees/[id]
```
- Delete
```bash
DELETE /api/employees/[id]
```

# Advanced Queries

- filter
```bash
GET /api/employees/?status=normal
```
- searching
```bash
GET /api/employees/?search=Alex
```
